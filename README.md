# Browser · 码道内置浏览器精准调整 web 页面

ICT 大赛云赛道赛题 1.5：通过「元素选中 → 评论标注 → 智能体精准优化 → CSS 双向编辑」体验码道内置浏览器的页面预览与标注能力，建立"所见即所得 + 精准定位"的页面开发认知。

## 作品内容

- `index.html`：宠物领养宣传页（宠物之家 Pet Haven）。卡片式布局，包含封面、宠物信息、特性标签、领养/了解更多按钮。

## 实践过程（对应实验手册三、四章）

### 3.1 在浏览器中预览页面
通过码道 IDE 内置浏览器预览 `index.html`，页面即时呈现运行效果，无需跳出 IDE。内置浏览器让智能体"看得见"页面——页面预览、元素选择、控制台日志构成智能体感知 Web 内容的入口。

### 3.2 选中元素并添加评论标注
在浏览器页签中单击"元素选择"图标，进入元素选择模式。选中「了解更多」按钮元素，点击"发送到会话"，在对话框中输入优化提示词："把按钮改成红色"。评论以气泡形式暂存，精准绑定到目标 DOM 元素，而非笼统描述整个页面。

### 3.3 评论驱动智能体精准修改
点击发送后，智能体根据评论对页面进行**局部优化**——只改动被标注的「了解更多」按钮元素。
- 提交记录 `8a999c0`（v2）：按钮背景由 `#f0f0f0` 灰改为 `#ff6b6b` 红，文字变白，并补充箭头语义。

### 3.4 通过 CSS 检查器双向调整
在浏览器页签中选中目标元素，在**组件树**和**设计面板**中对元素进行可视化修改：
- **组件树**：复制「健康认证」标签并粘贴出「亲人互动」标签（复制/粘贴元素）；
- **设计面板**：调整卡片宽度 360px→380px、圆角 20px→24px（位置/布局可视化编辑）；
- **CSS 规则**：卡片标题改为渐变色文字；为主按钮/次按钮补充 hover 状态样式。
- 提交记录 `01b8cb7`（v3）。

### 3.5 基于外部网站内容生成新页面（可选）
可在智能体模式输入指令打开目标外部网站，从外部页面选取背景图，输入指令让智能体替换本地页面背景并预览生成后的页面——验证智能体基于浏览器内容感知与再造页面的能力。

## 核心收获

1. **元素级标注是精准协作的关键**：评论/选中元素比自然语言更明确，能把美化需求精确绑定到目标 DOM；
2. **设计与代码双向编辑**：可视化设计面板与 CSS 代码视图指向同一对象，两种风格的开发者都能高效调整样式；
3. **所见即所得**：内置浏览器即时反馈修改效果，减少"改完再看"的返工循环。
